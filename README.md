# Retorno-medio-habitual-por-nivel-de-instrucao
Este trabalho tem como objetivo mostrar a tendência da remuneração média habitual por nível de instrução com a utilização de dados da PNAD contínua.
This project aims to show the trend of average regular income by level os education using data from continuos PNAD (Brazilian National Household Sample Survey)
