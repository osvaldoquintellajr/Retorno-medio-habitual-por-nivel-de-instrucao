# Retorno-medio-habitual-por-nivel-de-instrucao

Este trabalho tem como objetivo mostrar a tendência da remuneração média habitual por nível de instrução e estimar o prêmio salarial do ensino superior utilizando dados da PNAD contínua.

This project aims to show the trend of average regular income by level of education and estimate the higher education wage premium using data from continuos PNAD (Brazilian National Household Sample Survey)
